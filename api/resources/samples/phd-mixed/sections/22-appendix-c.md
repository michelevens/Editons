# Appendix C: Supplementary Tables

This appendix reports supplementary results referred to in Chapter 5. Table C.1 gives item-level descriptive statistics for all survey items; item wording is given in Appendix A. Table C.2 summarizes the four- and five-profile solutions of the latent profile analysis that were considered and rejected in Section 5.9.1. Table C.3 reports the structural model with teacher characteristics as covariates (Section 5.6.5).

Two features of Table C.1 are discussed in Chapter 5. The highest missingness occurred on the trust items, especially TR1 and TR4, and the use items showed a clear gradient: the three viewing and monitoring actions were reported far more often than the three actions that involve doing something with the data. Within the use scale, corrected item–total correlations ranged from .52 (Use6) to .68 (Use2), and deleting any single item would have lowered alpha.

*Note.* Standardized means (sample M = 0, SD = 1). Fit statistics for these solutions are given in Table 5.9. In both solutions the Willing but stalled profile is essentially unchanged; the additional profiles split the Engaged users and the Sceptics by level rather than by shape.

The comparison supports the decision in Section 5.9.1 to retain three profiles. Neither larger solution produced a new configuration of beliefs and use; each added a small group that differed from an existing profile in elevation only. The stability of the Willing but stalled profile across solutions also gave confidence that it was not an artifact of the number of profiles extracted, which mattered because it was the main sampling stratum for Phase 2.
